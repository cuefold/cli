# Cuefold CLI

Public releases for the Cuefold CLI.

## What you'll find here

- CLI release binaries for supported platforms
- SHA256 checksum files for release verification
- Installation assets, such as `install.sh`, when available

## Installing cuefold

Download the latest asset from the [Releases](https://github.com/cuefold/cli/releases) page and place the `cuefold` binary on your `PATH`.
